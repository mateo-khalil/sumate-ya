1. Resumen del Proyecto

Sumate Ya es una plataforma para conectar jugadores de fútbol amateur, permitiendo organizar partidos, sumarse a equipos, gestionar torneos y registrar resultados. El proyecto está estructurado como un monorepo gestionado con pnpm + Turborepo, y se compone de un frontend público, un backend con API GraphQL/REST y una suite de tests E2E.

2. Stack Tecnológico

6. Puesta en Marcha

6.1 Clonar el repositorio

git clone https://github.com/mateo-khalil/sumate-ya.git
cd sumate-ya

6.2 Instalar dependencias

pnpm install

6.3 Configurar variables de entorno

El proyecto requiere dos archivos .env: uno dentro de apps/backend/ y otro dentro de apps/frontend/. Ambos archivos deben contener exactamente las mismas variables que se listan abajo.

Importante: sin estos archivos las apps no van a levantar correctamente. Crear los archivos antes de ejecutar pnpm run dev.

Variables a usar

apps/backend/.env
apps/frontend/.env
Tip: en sistemas Unix podés crear un único .env en la raíz del repo y luego correr pnpm run sumate-ya para que el backend tome el archivo via symlink. En Windows hay que copiar el archivo manualmente a cada carpeta.

6.4 Levantar entorno de desarrollo

# Levanta frontend + backend en paralelo
pnpm run dev

# O por separado
pnpm run dev:frontend   # http://localhost:4321
pnpm run dev:backend    # http://localhost:4000

Comando Descripción

pnpm run test:e2e Tests E2E con Playwright
pnpm run codegen Regenera tipos desde el schema GraphQL
pnpm run kill:ports Libera los puertos 4321 y 4000 si quedaron ocupados

8. Testing

El monorepo cuenta con tests unitarios por app (Vitest) y una suite completa de tests end-to-end con Playwright en apps/testing/. 

# Instalar dependencias de Playwright (primera vez)
npm install --save-dev @playwright/test

# Correr toda la suite
npx playwright test

# Modo UI interactivo
npx playwright test --ui

# Solo Chromium
npx playwright test --project=chromium

# Modo debug
npx playwright test --debug
